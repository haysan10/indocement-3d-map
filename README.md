# Peta 3D Interaktif Kawasan PT Indocement Citeureup

Interactive WebGL 3D map viewer (`Three.js` + `glTF 2.0 / GLB`) exported from **Blender 5.3.0**.

- **Live Online Viewer:** https://haysan10.github.io/indocement-3d-map/
- **Model Asset:** [`indocement_3d_map_full.glb`](./indocement_3d_map_full.glb) (`11.95 MB`, `229,982` triangles, `54` PBR materials, `43` embedded WebP textures)

## Fitur Viewer
- Navigasi kamera 3D bebas (`OrbitControls`) + 6 preset sudut kamera (`Overview`, `Plant 14 & Kiln`, `Kubah & Konveyor`, `Gerbang Utama`, `Sungai & Masjid`, `Top-Down GIS`)
- 15 titik landmark interaktif lengkap dengan pencarian lokasi dan panel info area
- 3 mode pencahayaan (`Siang`, `Sore`, `Malam`) dengan lampu kawasan & kaca bangunan menyala di malam hari
- Mode `Wireframe`, `Auto-Orbit`, toggle `Pin Map`, serta tombol **Download GLB** langsung
